# Cobrança — guia orientado por gateway

Na v1 do RastrackDash **não há cobrança fechada** (Asaas/split da PalmUP) para o aluno cobrar o cliente final.

## Opções do aluno

1. **Não cobrar** pelo painel (cobrança manual/externa)
2. **Asaas próprio** (BYO)
3. **Hotmart / outro gateway** (BYO)

## O que o produto oferece

- Conceitos de referência do WppTrack (`PaymentCharge`, ativação por pagamento) como padrão mental
- Pontos de extensão no código (quando exportados) para conectar um adaptador de pagamento
- Este guia passo a passo (em evolução)

## Fora de escopo v1

PalmUP não opera split nem gateway do aluno. A monetização dos clientes finais é responsabilidade do aluno.
